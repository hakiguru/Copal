Every kind of help counts.

- **Test printers** — print a test file and report. This is the most valuable help right now.
- **Share resin settings** from the calibration wizard.
- **Report bugs** and ideas in [Issues](https://github.com/hakiguru/Copal/issues).
- **Translate** the interface (English and Russian first, more later).
- **Write code** — see [[Building from source|Building-from-Source]] and pick an issue.

## Rules for code
- Read [AGENTS.md](https://github.com/hakiguru/Copal/blob/main/AGENTS.md) first.
- Clean-room: don't copy code from GPL/AGPL or closed slicers.
- Short commits in plain English.
- New features come with tests.
