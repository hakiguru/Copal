> [!NOTE]
> 🚧 This page describes a planned feature. It arrives in **Copal 0.4**. Details may change.


Defaults are Blender-like. You can change every key in **Settings → Hotkeys**.

| Key | Action |
|---|---|
| `Tab` | Object mode ↔ Edit mode |
| `G` / `R` / `S` | Move / Rotate / Scale, then `X` `Y` `Z` to lock an axis, type a number, `Enter` |
| `1` `2` `3` | Vertex / Edge / Face select (Edit mode) |
| `A` / `Alt+A` | Select all / none |
| `Shift+D` | Duplicate |
| `X` / `Delete` | Delete |
| `E` | Extrude |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| Numpad `1` `3` `7` | Front / Right / Top view |
| Middle mouse | Orbit · `Shift` pan · wheel zoom |
| `F3` / `Ctrl+P` | Command palette |
| `` ` `` | Console |
