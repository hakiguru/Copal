| Key | Action |
|---|---|
| `G` / `R` / `S` | Move / Rotate / Scale handles |
| Ctrl while dragging | Snap to steps |
| `Ctrl+D` | Duplicate |
| `X` / `Delete` | Delete |
| `Esc` | Deselect, leave the Select / Add tool, or cancel a running export |
| `Delete` (Prepare) | Delete the selected supports |
| `Shift`+click (Prepare, Select tool) | Add a support to the selection |
| `Alt+1` / `Alt+2` / `Alt+3` | Show or hide tools / settings / console |
| `F` / double-click | Frame the plate and models |
| `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | Open / Save / Save as |
| `Ctrl+I` | Import models |
| `Ctrl+E` | Slice & export |
| `Ctrl+,` | Preferences |
| Left drag | Orbit (on empty space) or move a model over the plate |
| Right / middle drag, `Shift` + drag | Pan |
| Wheel | Zoom to the cursor |
| ↑ / ↓, wheel | Next / previous layer in the layer preview |

Coming with Blender-style editing (0.6): `Tab` for Edit mode, `X` `Y` `Z` axis locks after
`G` / `R` / `S`, typed values, vertex / edge / face selection. Editable keys arrive in 0.4.
