**Is Copal really free?**
Yes. No ads, no subscription, no account, no locked features. MIT license.

**Will it work on my old laptop?**
That's what Copal Lite is for. It runs on OpenGL 2.1 and even without a graphics card.

**Does it support my printer?**
See [[Supported printers|Supported-Printers]]. If it's missing, you can help add it.

**Why does my resin need calibration?**
Exposure changes with color, batch and temperature. See [[Calibration wizard|Calibration-Wizard]].

**Can I use Copal without a mouse?**
Yes — the [[Command line|Command-Line]] does everything.

**macOS?**
Not planned for now. The code is cross-platform, so it can come later.

**What does the name mean?**
Copal is young natural resin, on its way to becoming amber.
