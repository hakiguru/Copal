> 🚧 This page describes a planned feature. It arrives in **Copal 0.3**. Details may change.


All three editions use the **same engine** and have the **same features**.
They only differ in how they look and how much your computer needs.

| | Copal | Copal Lite | Copal CLI |
|---|---|---|---|
| Interface | Modern, big 3D view, effects | Simple panels, plain 3D view | Terminal |
| Graphics needed | Vulkan / DirectX 12 / OpenGL 3.3 | OpenGL 2.1, or none (software) | None |
| Good for | Gaming PCs, modern laptops | Old laptops, integrated graphics | Scripts, servers, batch jobs |
| Blender-style editing | Full | Through menus and command palette | Through commands |

## Not sure?

- Start with **Copal**. If it feels slow or does not start, install **Copal Lite**.
- If you have no desktop at all, see [[Running Copal Lite without a desktop|Running-Without-Desktop]].
- Projects (`.copal` files) open in every edition, so you can switch at any time.
