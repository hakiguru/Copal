# Lychee Slicer 7.6.6 — black-box notes (October 2026)

Source: screenshots of the owner's own Lychee install (Lite edition, Plus trial expired) and the
headers of `.goo` files the owner sliced and printed. No binaries were opened. These notes record
**what Lychee does and offers**, as goals for Copal. Our designs and code are our own.

## Workflow and layout

- Top: four big steps — **Library**, **Layout**, **Prepare**, **Export**. Left: a vertical toolbar
  with icon + label buttons that change with the step. Right: one floating panel for the active tool.
- Bottom-left corner: always-visible print info (printer, resin, layer height, exposure, height,
  estimated time / resin, clickable).
- Layout tools: Select, Arrange, Move, Rotate (with *on plate*, *auto orientation*, *reset*),
  Scale, Copy, Mirror, Tools (cut / split), Measure, Batch, Magic (one-click prepare).
- Prepare tools: Support, Raft, Hollow, Visibility, Batch, Magic.
- Object editor panel: file path, *auto update* from disk, object repair, exact rotation fields.
- Primitives menu: cube, sphere, cone, cylinder, torus, icosahedron, more + text.
- 3D printing history: every exported file with date, printer, resin, print time, and a rating.
- Preferences are a searchable list: history, autosave (every 5 min), backups, global settings,
  library, account, printers & resins, shortcut editor, theme editor (overhang / island colors),
  algorithm settings, menu settings, 3D mouse, mobile notification, model repair, external tools.

**For Copal:** keep the 4-step header idea as our workflow tabs; the always-visible print info
block is useful; history of exported files with a "did it print well?" rating feeds calibration.

## Supports

Panel options seen:

| Setting | Value seen |
|---|---|
| Support type | Cone (tip diameter 0.30 mm, tip length 2.00 mm, diameter 1.00 mm) |
| Mini supports | toggle |
| Presets | Light / Medium / Heavy / Custom |
| Modes | Auto, Structure, Manual, Island, Proximity |
| Auto support version | Classic / Plus |
| Density | High |
| Auto-bracing, auto-parent, auto-lift | on |
| Overhang angle | 45° |
| Safe distance to object | 0.5 mm |
| Z limit for adaptive base | 2.0 mm, adaptive base offset 1.0 mm |
| Search for ground | 20 mm |
| Auto lift height | 5.0 mm |
| Islands detector accuracy | Normal |

Selection filters for editing supports: all, tips/bases, tips, tips/middles, contacts, line.
Shortcuts: Ctrl+1/2/3 apply light/medium/heavy to selected supports, Alt+R recalc,
Alt+V make vertical, Alt+S straight, Alt+P pillar, Alt+B bracing, Alt+Shift+P parenting.

**Observed result:** the XYZ calibration cube, auto-supported with the *Classic* (free) generator
at the settings above and tilted ~33°/−16°, **detached from the supports during the print and
stayed on the film**. Figure parts supported with the *Plus* generator printed well.

**Goals for Copal 0.3:**
- Supports must be strong enough on the *first* try for a solid tilted cube — this is our
  regression test. More, thicker supports near the lowest points and along the first edges.
- Bracing and parenting on by default.
- Island check after generation, with every island either supported or reported.
- Presets similar in spirit (light / medium / heavy), but tuned on real prints.

## Hollowing

Hollow tool tabs: **Holes**, **Hollowing 3D**, **Voxel Hollowing 3D**, **Hollowing 2D**, **Blockers**,
plus a **suction cup detector**.

| Tool | Settings seen |
|---|---|
| Holes | cylinder, diameter 3.0 mm, penetration 4.0 mm, real-time drain-hole check, 3D hole conversion with cap gap 0.5 mm |
| Hollowing 3D | wall thickness 2.5 mm, quality 1.0 |
| Voxel hollowing 3D | thickness 2.5 mm, detect pockets, add infill, voxel editing (mark voxels to hollow / block) |
| Hollowing 2D | thickness 2.5 mm, infill %, pattern size 1.0 mm (applied at slicing) |
| Blockers | boxes that keep parts solid |

**Goals for Copal 0.5:** wall thickness default 2.5 mm; 3D hollowing that makes a real inner
surface (so drain holes and internal supports can be checked); suction-cup / resin-trap check
before slicing; blockers.

## Auto orientation

Available in Layout → Rotate (Plus in 7.6.6). Copal's version: choose the angle that minimizes
islands and peel area and keeps the most important surface (marked by the user) free of supports.

## Export

`.goo` or `.ctb`, normal or fast slicing engine, anti-aliasing (off → levels), plate choice,
export of the supported model as STL/OBJ, scene export.
